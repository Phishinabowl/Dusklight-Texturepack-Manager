# Contributing

Thanks for your interest in helping with this project.

This tool is being built to make Dusklight texture pack preparation easier and safer. Contributions are welcome, especially bug reports, real-world texture pack edge cases, documentation improvements, and focused code changes.

## Good Ways To Help

- Test the script with real texture packs.
- Report confusing prompts or unsafe behavior.
- Share examples of pack folder layouts that are not handled well.
- Suggest improvements to output structure and naming conventions.
- Improve documentation.
- Submit focused pull requests.

## Before Opening A Pull Request

Please try to keep changes focused. A small pull request that fixes one behavior is much easier to review than a large pull request that changes several unrelated things.

For code changes:

- Explain what problem the change solves.
- Include the steps you used to test it.
- Avoid unrelated formatting churn.
- Do not remove existing safety prompts unless the change explains why.
- Be careful with file deletion, overwrite, and rename behavior.

## AI-Generated Contributions

AI tools may be used as assistants, but contributors are responsible for understanding, reviewing, and testing anything they submit.

Please do not submit large AI-generated changes that you cannot explain or maintain.

## Project Direction

The current script is a stepping stone toward a more complete texture pack manager. Some features may be intentionally kept out of the script if they make more sense in a future GUI workflow.

When in doubt, open an issue or discussion before doing a large implementation.
